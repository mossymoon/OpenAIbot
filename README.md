# OpenAIbot

**OpenAIbot** — Telegram-бот на **Python** и **aiogram 3** с интеграцией **OpenAI API** для общения с ИИ, анализа изображений и генерации картинок.

Проект демонстрирует работу с асинхронными API, обработчиками Telegram-сообщений, конечными автоматами состояний (FSM) и базой данных через SQLAlchemy.

## Возможности

- **Диалог с ИИ:** обработка текстовых запросов пользователя и получение ответов языковой модели OpenAI.
- **Анализ фотографий:** обработка отправленных изображений, в том числе с текстовым описанием.
- **Генерация изображений:** создание изображений по текстовому запросу через OpenAI API.
- **Учет пользователей:** регистрация пользователей Telegram в локальной базе SQLite.
- **Учет использования:** хранение баланса пользователя и списание стоимости запросов согласно настройкам моделей.
- **Административная рассылка:** отправка сообщений зарегистрированным пользователям через команду `/newsletter` с проверкой Telegram ID администратора.
- **FSM:** управление состояниями диалога и последовательностью действий пользователя средствами aiogram.

## Технологии

- **Python** — основной язык разработки.
- **aiogram 3** — асинхронный Telegram Bot API-фреймворк.
- **OpenAI API** (`openai`, `aiohttp`) — интеграция с ИИ-моделями.
- **SQLAlchemy 2**, **aiosqlite** — асинхронное взаимодействие с БД.
- **SQLite** — хранение данных пользователей, балансов и настроек моделей.
- **Docker** — контейнеризация приложения.

## Установка и запуск

### 1. Клонирование репозитория

```bash
git clone https://github.com/mossymoon/OpenAIbot.git
cd OpenAIbot
```

### 2. Виртуальное окружение и зависимости

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r reqs.txt
```

На Windows для активации окружения используйте `.venv\Scripts\activate`.

### 3. Настройка токенов

В текущей реализации приложение загружает токены из локального файла `config.py`. Создайте его в корневой директории проекта:

```python
TOKEN = "YOUR_TELEGRAM_BOT_TOKEN"
AITOKEN = "YOUR_OPENAI_API_KEY"
```

- Токен Telegram-бота можно получить у [@BotFather](https://t.me/BotFather).
- API-ключ OpenAI создается на [OpenAI Platform](https://platform.openai.com/api-keys).
- **Не добавляйте `config.py` с настоящими токенами в Git.** Убедитесь, что он указан в `.gitignore`.

### 4. Запуск приложения

```bash
python run.py
```

При старте приложение создает таблицы SQLite, если они отсутствуют.

## Важное замечание о балансе и моделях

В текущей реализации новый пользователь регистрируется с балансом `0`. Для использования функций ИИ требуется **положительный баланс**. Код расчета стоимости запросов также ожидает наличие записей о ценах моделей в таблице `ai_models`.

Автоматическое пополнение баланса и первоначальное заполнение цен моделей в исходном проекте не предусмотрены. Поэтому перед локальным тестированием этих функций необходимо вручную подготовить соответствующие записи в БД и тестовый баланс.

В обработчиках проекта упоминаются модели `gpt-5.2` и `gpt-image-1.5`. Доступность моделей и тарификация зависят от настроек и доступа вашего аккаунта OpenAI API.

## Запуск через Docker

В проекте есть Dockerfile с именем `dockerfile` (в нижнем регистре). Перед сборкой проверьте, что `.dockerignore` исключает `config.py`, `.env` и другие файлы с секретами.

Приложению требуется `config.py` во время работы, поэтому удобнее **подключать его как файл при запуске**, а не включать в Docker-образ:

```bash
docker build -f dockerfile -t openaibot .
docker run --rm -v "$(pwd)/config.py:/app/config.py:ro" openaibot
```

Эти команды не обеспечивают сохранение SQLite-базы за пределами контейнера. Для постоянного использования потребуется дополнительно настроить том или подключение локального каталога.

## Безопасность

- Храните Telegram-токен и ключ OpenAI API вне системы контроля версий.
- Исключите `config.py`, `.env`, базы данных, IDE-файлы и временные изображения из Git и Docker-контекста.
- Проверяйте **всю историю коммитов**: удаление секрета из последней версии не удаляет его из предыдущих коммитов.
- В текущем варианте Telegram ID администратора задан в `app/admin.py`. При дальнейшем развитии проекта его лучше вынести в конфигурацию.
- Если ключ ранее попадал в публичный репозиторий или опубликованный Docker-образ, его необходимо отозвать и заменить новым.

## Статус проекта

Личный проект на Python, предназначенный в том числе для демонстрации навыков разработки Telegram-ботов и интеграции внешних API. Для полноценного развертывания еще требуется доработать начальную настройку стоимости моделей, управление балансом и конфигурацию окружения.
